# mandas-website

Marketing website for [mandas.io](https://mandas.io) — the open core payment simulation platform for fintech and banking engineering teams.

Built with HTML/CSS. Deployed on Vercel.

---

## About Mandas

Mandas lets developers test the full lifecycle of SEPA and SWIFT payment transactions — including edge cases and failure flows (R-transactions, rejects, returns) that real banking environments make difficult or impossible to trigger without manual intervention.

**Stop emailing banks to test your integrations.**

→ [mandas.io](https://mandas.io)  
→ [github.com/mandas-io](https://github.com/mandas-io)

---

## Development

This is a static site. No build step required.

Clone the repo and open `index.html` in your browser, or use any static file server:

```bash
npx serve .
```

Changes pushed to `main` are deployed automatically via Vercel.
